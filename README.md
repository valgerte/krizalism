# Кризализм

Звуковая фиджет-доска и браузерный синтезатор. На нём можно расслабляться простыми повторяющимися жестами (нажимай, вращай, касайся, удерживай) и играть музыку: мелодии, аккорды, ритм, слои голоса.

- Figma: https://www.figma.com/design/e7D2PjvEzVcUykof5qtW5n/?node-id=1-154
- Сайт с версиями (GitHub Pages): https://valgerte.github.io/krizalism/

## Версии

В репозитории три версии. Каждая лежит в своей папке и открывается отдельно, файлы не пересекаются.

| Папка | Версия | Технологии | Ссылка |
|---|---|---|---|
| `prototype-02/` | Сенсорная музыкальная станция с окном «Проекция» | Web Audio API, AudioWorklet, ES-модули, Canvas, без библиотек | `/prototype-02/` |
| `tone-v0.5/` | Kawaii-плагин из фиджетов Figma | Tone.js 14.7.77, один файл со встроенными изображениями | `/tone-v0.5/` |
| `four-gestures/` | «Звук приобретает форму»: четыре жеста для аудиовизуального исполнения | Web Audio API, AudioWorklet, Canvas, 7 WAV-сэмплов | `/four-gestures/` |

Новую версию добавляют новой папкой со своим `index.html` и карточкой в корневом `index.html`. Старые папки не меняют, поэтому к любой можно вернуться.

## Запуск

Нужен https или localhost: ES-модули, AudioWorklet и микрофон не работают при открытии файла через `file://`.

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

На GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll.

Один экран: шапка, режим, характер звука, мастер, четыре инструмента и тактильные фиджеты.

| Блок | Что делает |
|---|---|
| Режим «Успокоиться / Сфокусироваться» | 68 BPM, мягкий тембр, воздушные аккорды, больше пространства / 96 BPM, тёплый тембр, повторяющийся бас, короче пространство |
| Характер «Мягкость / Стекло / Сон» | базовая частота импульсов, общий фильтр, спад, реверберация и эхо |
| Мастер | громкость, пространство, эхо, запись общего микса (WebM/MP4, до 5 минут) |
| 05 Синтезатор | 25 клавиш C4–C6, мышь или A W S E D F T G Y H U J K O L P ; в любой раскладке; полифония; тембр, яркость, уровень |
| 06 Ритм-секция | 16 шагов × 3 звука (низ, щелчок, шорох), подложки «Течение / Пульс / Шаги», темп 50–130, своя минусовка до 30 МБ |
| 07 Вокальный лупер | микрофон, прослушивание, до 6 слоёв по 1/2/4 такта, запись с границы цикла, приглушение и удаление слоёв |
| 08 Мастер-эффекты | «Чисто / Дымка / Цифра», искажение, цифровое зерно, фильтр |
| 01 Маленькие радости | 9 пузырьков, мягкие хлопки |
| 02 Своя орбита | кольцо щёлкает при вращении и уводит голос лупера в эхо и реверберацию |
| 03 Тихий шорох | шёлк шуршит под пальцем; пока касаешься, ведёт общий фильтр |
| 04 Можно отпустить | облако звучит ровным фоном и работает как педаль: отпущенные клавиши тянутся, пока облако удерживается |

### Как создаётся звук

```
Синтезатор: осциллятор (синус / треугольник / пила) → фильтр (яркость) → огибающая → уровень синтезатора ┐
Ритм: синусный удар (низ) · шум через полосовой фильтр (щелчок) · шум через ВЧ-фильтр (шорох) → уровень ритма ┤
Подложки: аккорды / бас / арпеджио по прогрессии → уровень ритма                                         ┤
Фиджеты: хлопки (синус со спадом высоты + шумовой импульс), шорох (сглаженный шум), облако (3 синуса)    ┤
Голос: микрофон → AudioWorklet-запись слоёв → реверберация 4 с + delay 375 мс → уровень голоса           ┘
          → общая шина → waveshaper (tanh-сатурация + квантование амплитуды) → lowpass
          → сухой сигнал + свёрточная реверберация + delay (feedback 0.22) → компрессор → мастер
          → динамики · MediaRecorder · анализатор уровня для проекции
```

Ритм планируется по часам AudioContext с опережением 120 мс, поэтому не зависит от нагрузки интерфейса. Слои лупера выравниваются по общей сетке с ритмом; после первой записи темп фиксируется.

### Проекция

Кнопка «◉ Проекция» открывает отдельное окно для проектора или второго экрана; двойное нажатие — полный экран. Окно открывается пустым и рисуется со страницы инструмента. Если браузер не дал открыть окно, проекция появляется поверх страницы.

| Действие | След на проекции |
|---|---|
| пузырёк | мягкий шар сжимается, расходятся кольца |
| кольцо | орбита из 12 бусин поворачивается за рукой |
| шёлк | след из складок за пальцем |
| облако | дышащее облако в центре |
| нота | шар по высоте ноты поднимается, пока клавиша нажата |
| ритм | волна (низ), искры (щелчок), зерно (шорох) |
| слой голоса | новое концентрическое кольцо |
| «Цифра» | пикселизация картинки |
| громкость | фоновые пятна палитры дышат с уровнем |

Файлы: `visbus.js` — шина событий и уровень звука; `projection.js` — рисование на canvas; `projection.html` — самостоятельная страница проекции для второй вкладки того же сайта (связь через BroadcastChannel).

## Версия 0.5 — kawaii-плагин из фиджетов (Tone.js)

Четыре инструмента-жеста в одной панели с объектами из Figma (капитошка, бутылочка, тюлень, «пушистик», спиннер, карабин, клавиатура-брелок).

| Инструмент | Что делает |
|---|---|
| 1 · Нажимай | ритм на пупырках pop-it 4×16, подложки, тоника, своя минусовка; клавиатура-брелок на 25 клавиш, пружина-карабин для высоты, «держать» |
| 2 · Удерживай | MIDI-сэмплер из фиджетов: 8 сэмплов-игрушек, кликер записывает свой звук в новый сквиш; цикл, фиксация, Web MIDI |
| 3 · Касайся | сцена-поверхность: X — фильтр, Y — глубина эффектов; 6 сцен обработки; тревоги на сцене наполняются музыкой и растворяются |
| 4 · Вращай | спиннер-лупер голоса: 6 бусин-слоёв, раскрутка уводит голос по панораме |

Режимы «Сфокусироваться» (светлый) и «Отдохнуть» (тёмный, реверберация 5 с, медленнее визуал). Перформанс по главам истории (N / B), «Сцена» на весь экран и «Экран 2» для проектора.

Мастер-цепь: фильтр 24 дБ → драйв → зерно → хорус → эхо → реверберация → тон режима → громкость → лимитер −1 дБ → выход и запись.

## Четыре жеста — «Звук приобретает форму»

Версия, собранная в ChatGPT по тем же требованиям (исходный README лежит в истории автора; ниже — суть).

| Жест | Что делает |
|---|---|
| 01 Нажимай — ритм под пальцами | три пупырки-ударных (низ, щелчок, шорох) и три пупырки-подложки (течение, пульс, шаги); секвенсор, темп и своя минусовка в раскрывающихся настройках |
| 02 Удерживай — коллекция звуков | семь оригинальных предварительно отрендеренных WAV-сэмплов-фигурок и восьмая — свой звук: запись с микрофона до 10 с или файл до 30 с; клавиши A S D F G H J K, Web MIDI |
| 03 Касайся | XY-поверхность: общий low-pass и зерно, reverb и delay |
| 04 Вращай | кольцо меняет reverb и delay голоса; тактовый лупер до 6 слоёв |

Светлый режим — «Сфокусироваться», тёмный — «Отдохнуть». Жесты и ритм оставляют следы на canvas; «◉ Проекция» открывает окно с аудиореактивным фоном, двойное нажатие — полный экран. Обычной фортепианной клавиатуры в этой версии нет.

## Музыкальные референсы

Billie Eilish — when the party's over, bellyache; Melanie Martinez — Soap, Sippy Cup, Cake, Cry Baby. Из анализа: тёмный спектр и мощный низ (саб-слой, пресет «Глубина»), редкие атаки и паузы (разреженные паттерны, длинная реверберация), яркие игрушечные звуки как контраст. Записи в репозиторий не включены, все звуки синтезируются в браузере.

## Промпт-дизайн

Работа шла с ИИ (Claude, ранний прототип — ChatGPT) по мастер-промпту автора: роль, концепция, запреты (не лендинг, без декоративных органов управления, без обещаний нереализованного) и приоритеты (звук → концепция → цельная консоль). Ключевые правки автора по итерациям:

1. Взять из Figma не только палитру, а сами объекты и метафоры.
2. Синтезатор не должен выглядеть как синтезатор: фиджет-борд по форме, аудиоперформанс по функции.
3. Фиджеты должны не соседствовать с инструментами, а быть ими.
4. Собрать экран точно по макетам прототипа 02; добавить проекцию для выступления.

Название, концепция, палитра, визуальные решения и выбор версий — автора. ИИ писал код, предлагал звуковую архитектуру и проверял работу в браузере.

## Что проверено

В headless Chromium: игра и отпускание аккордов без зависших нот, русская раскладка, удержание нот облаком, ритм и пузырьки, шёлк и кольцо, виртуальный микрофон и запись слоя, эффекты, тёмная тема, окно проекции и запасной слой, ширина 390 px без горизонтальной прокрутки, отсутствие ошибок JavaScript.

Не проверено: живой микрофон и задержка мониторинга, реальный проектор, Safari и телефоны.

## План

1. Записать скринкаст: включение → фиджеты → синтезатор и ритм → лупер → проекция.
2. Проверить на телефоне и в Safari, настроить громкости слоёв.
3. Сохранение сессии (паттерн, настройки, слои).
4. Собрать итоговый интерфейс в Figma.
